# Food Ordering App

A React app built with Parcel.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run builddev
```

Create a production build:

```bash
npm run buildprod
```
Create folder-
1. add command npm install -D parcel
2. npm init
3. npm install react react-dom
4. add files index.html, app.js and index.css
